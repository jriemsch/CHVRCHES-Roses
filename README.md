# CHVRCHES — Roses (learn)

Unofficial fan lyric-learning mini-game for GitHub Pages.

## Play

After you enable **Settings → Pages → Deploy from branch `main` / root**, open:

`https://<your-github-username>.github.io/CHVRCHES-Roses/`

## Local preview

```bash
python3 -m http.server 8080
```

(Run from the repo root.)

Then open `http://127.0.0.1:8080/`.

Lyrics and branding belong to their respective rights holders; this is a personal fan project.
